# 내 정령 그림 넣기

이 폴더에 그림 파일을 `정령id.png` (또는 .jpg, .webp) 이름으로 넣으면, 게임의 정령 그림이 그 파일로 바뀝니다.
예: `lightning.png`, `river.jpg`

- 이 폴더의 그림은 내 컴퓨터에서만 쓰이고 GitHub에 올라가지 않습니다(.gitignore).
- 자동 업데이트를 해도 지워지지 않습니다.
- 가로로 긴 그림(16:9 정도)이 가장 잘 어울립니다.
- 그림을 넣은 뒤 브라우저를 새로고침하세요.
- 저작권이 있는 그림은 개인적으로만 사용하세요.
