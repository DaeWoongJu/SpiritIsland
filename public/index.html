    정령 선택

    정령섬 규칙 요약

    모두가 섬의 정령이 되어 협력해 침략자를 몰아내는 게임입니다. 한 턴은 다음 순서로 진행됩니다.

    1. 정령 단계 — 성장 옵션 하나를 골라 실행(존재 추가, 카드 회수, 권능 카드 획득, 에너지 획득) → 에너지 트랙에서 드러난 가장 큰 값만큼 에너지 획득 → 카드 수 트랙 값만큼 권능 카드를 에너지를 지불하고 냅니다.
    2. 빠른 권능 — 빠른 카드와 원소 조건을 만족한 빠른 내재 권능을 사용합니다.
    3. 침략자 단계 — 획득한 공포 카드 해결 → 약탈(침략자가 피해: 탐험가1·마을2·도시3. 피해 2 이상이면 황폐 추가, 다한이 피해를 받고 살아남은 다한은 1개당 피해 2로 반격) → 건설(침략자가 있는 지역에 마을, 마을이 도시보다 많으면 도시) → 탐험(해안이거나 마을/도시가 있거나 인접한 지역에 탐험가) → 카드가 한 칸씩 이동합니다.
    4. 느린 권능 — 느린 카드와 느린 내재 권능을 사용합니다.
    5. 시간 흐름 — 피해·방어 초기화, 사용한 카드는 버림 더미로 (성장의 "카드 모두 회수"로 되찾습니다).

    용어

    • 존재: 정령이 있는 곳. 권능의 사거리는 존재(또는 성지)에서 셉니다. 트랙에서 존재를 꺼내면 에너지/카드 수가 늘어납니다.
    • 성지: 존재가 2개 이상 있는 지역.
    • 원소: 이번 턴에 낸 카드의 원소 합. 내재 권능과 대형 권능의 추가 효과 조건이 됩니다.
    • 밀어내기/모으기: 인접 지역으로 내보내기 / 인접 지역에서 데려오기.
    • 방어 X: 그 지역에서 침략자가 주는 약탈 피해를 X만큼 줄입니다.
    • 공포: 마을 파괴 1, 도시 파괴 2 및 권능으로 얻습니다. 공포 풀이 차면 공포 카드 1장을 얻고, 3장마다 공포 단계가 올라 승리가 쉬워집니다.
    • 황폐: 이미 황폐가 있는 지역에 황폐가 추가되면 인접 지역으로 번집니다. 황폐가 추가된 지역의 존재는 1개씩 파괴됩니다.

    승리 / 패배

    • 승리: 공포 1단계 — 침략자 0 / 2단계 — 마을·도시 0 / 3단계 — 도시 0 / 공포 카드를 모두 획득.
    • 패배: 황폐 카드가 두 번 고갈 / 정령의 존재가 섬에서 모두 사라짐 / 탐험해야 하는데 침략자 덱이 비어 있음.
