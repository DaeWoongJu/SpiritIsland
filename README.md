# 🌋 정령섬 온라인 (Spirit Island Online)

협력 보드게임 **정령섬(Spirit Island)** 을 친구와 함께 각자의 컴퓨터에서 브라우저로 플레이할 수 있게 만든 팬메이드 구현입니다. (1~4인)

- **방장(서버를 켜는 사람)**: 이 프로그램을 내려받아 실행합니다. 한 번 설치하면 이후에는 **바탕화면 아이콘 더블클릭**으로 켤 수 있습니다.
- **친구**: 아무것도 설치할 필요 없이 방장이 알려준 **주소를 브라우저(크롬/엣지 권장)로 열기만** 하면 됩니다.

> 비공식 팬 프로젝트입니다. 정령섬은 R. Eric Reuss / Greater Than Games의 저작물입니다.
> 카드 효과는 원작을 바탕으로 했지만, 온라인 진행을 위해 일부 단순화되어 있습니다.

## 1. 방장: 처음 설치하기

### 1-1. Node.js 설치 (최초 1회)

1. <https://nodejs.org/ko/download> 에 접속합니다.
2. **LTS** 버전 설치 파일을 받아 실행하고, 기본 설정 그대로 "다음"을 눌러 설치합니다.
3. 설치가 끝나면 컴퓨터를 한 번 재시작하면 확실합니다.

> 설치 확인: Windows는 `명령 프롬프트`, macOS는 `터미널`을 열고 `node -v` 를 입력했을 때 `v20.x.x` 같은 숫자가 나오면 성공입니다.

### 1-2. 게임 파일 내려받기

**방법 A — ZIP으로 받기 (쉬움)**

1. GitHub 저장소 페이지 위쪽의 초록색 **`<> Code`** 버튼 → **Download ZIP** 을 누릅니다.
   (브랜치 목록에서 `claude/board-game-multiplayer-m1i0cr` 를 고른 뒤 받으세요. main 에 병합된 뒤라면 main 그대로 받으면 됩니다.)
2. 받은 ZIP 파일을 **압축 해제**합니다. (예: `문서\SpiritIsland` 폴더)
   ⚠ ZIP 안에서 바로 실행하지 말고 반드시 압축을 푼 폴더에서 실행하세요.

**방법 B — git 사용**

```bash
git clone https://github.com/DaeWoongJu/SpiritIsland.git
cd SpiritIsland
git checkout claude/board-game-multiplayer-m1i0cr
```

## 2. 방장: 게임 켜기 (아이콘 만들기)

### 🪟 Windows

1. 압축을 푼 폴더에서 🌋 **`정령섬.exe`** (정령섬 아이콘이 붙은 파일)를 더블클릭합니다.
   - **처음 실행하면 바탕화면과 시작 메뉴에 "정령섬" 아이콘이 자동으로 생깁니다.** 다음부터는 바탕화면 아이콘만 더블클릭하세요.
   - 처음 한 번은 필요한 파일을 자동으로 설치합니다(인터넷 필요, 수십 초).
   - 검은 창(서버)이 열리고, 잠시 후 **브라우저에 게임이 자동으로 열립니다.**
   - ⚠ 게임하는 동안 **검은 창을 닫지 마세요.** 닫으면 서버가 꺼집니다.
   - 서버가 이미 켜져 있을 때 아이콘을 누르면 브라우저만 다시 열립니다.
   - "Windows의 PC 보호" 파란 창이 뜨면 **추가 정보 → 실행** 을 누르세요. (서명되지 않은 개인 제작 프로그램이라 나오는 경고입니다)
   - "방화벽에서 Node.js 허용" 창이 뜨면 **허용**(개인 네트워크 체크)을 누르세요. 같은 와이파이 친구가 접속하려면 필요합니다.
2. 바탕화면 아이콘이 안 보이면:
   - 바탕화면에서 **F5**(새로 고침)를 눌러 보세요.
   - 또는 `create-shortcut-windows.bat` 을 더블클릭하거나, `정령섬.exe` 우클릭 → **바로 가기 만들기** 후 바탕화면으로 옮기세요.
   - 게임 폴더를 다른 곳으로 옮겼다면 바로가기를 다시 만드세요.
3. `정령섬.exe` 가 동작하지 않으면 같은 폴더의 `start-windows.bat` 을 직접 더블클릭해도 똑같이 실행됩니다.

### 🍎 macOS

1. 폴더에서 **`start-mac.command`** 를 더블클릭합니다. 터미널 창이 열리고 브라우저에 게임이 열립니다.
   - "확인되지 않은 개발자" 경고가 나오면: 파일을 **우클릭 → 열기 → 열기**.
   - "권한이 없습니다"가 나오면 터미널에서 한 번만: `chmod +x start-mac.command scripts/*.sh`
2. **앱 아이콘 만들기**: 터미널에서 게임 폴더로 이동 후 `bash scripts/create-mac-app.sh` 실행
   → `응용 프로그램`(Launchpad)에 🌋 **정령섬** 앱이 생깁니다. Dock 으로 끌어다 놓으면 편합니다.

### 🐧 Linux

```bash
./start-linux.sh                      # 실행
bash scripts/create-shortcut-linux.sh # 앱 메뉴/바탕화면 아이콘 만들기
```

### 💻 명령어로 직접 실행 (모든 OS)

```bash
npm install     # 최초 1회
npm run play    # 서버 실행 + 브라우저 자동 열기  (npm start 는 브라우저를 열지 않음)
```

포트를 바꾸려면: Windows `set PORT=8080 && npm start`, macOS/Linux `PORT=8080 npm start`

### 🌐 브라우저에서 "앱으로 설치" (방장·친구 모두 가능)

크롬/엣지에서 게임을 연 뒤, 첫 화면의 **"⬇ 정령섬을 앱으로 설치"** 버튼(또는 주소창 오른쪽의 설치 아이콘 ⊕)을 누르면
게임이 **독립된 창 + 바탕화면/작업표시줄 아이콘**으로 설치됩니다.

- 이 기능은 `http://localhost` 주소나 `https://` 주소(아래 터널 방식)에서만 나타납니다.
- `http://192.168...` 같은 주소에서는 대신 크롬 메뉴 **⋮ → 전송, 저장, 공유 → 바로가기 만들기 → "창으로 열기" 체크** 로 아이콘을 만들 수 있습니다.
- 설치한 앱 아이콘도 **서버가 켜져 있어야** 동작합니다.

---

### 🔄 자동 업데이트

**한 번 설치한 뒤에는 ZIP을 다시 받을 필요가 없습니다.** `정령섬.exe`(바탕화면 정령섬 아이콘)로 실행할 때마다
GitHub에서 새 버전을 확인하고, 있으면 자동으로 내려받아 설치한 뒤 게임을 켭니다. (파란 업데이트 창이 잠깐 뜹니다)

- 서버가 이미 켜져 있을 때는 업데이트하지 않습니다. 서버 검은 창을 닫고 다시 실행하면 업데이트됩니다.
- 직접 업데이트하려면 게임 폴더의 `update-windows.bat` 을 더블클릭하세요.
- macOS/Linux 는 `start-mac.command` / `start-linux.sh` 가 시작할 때 자동으로 업데이트합니다. (수동: `bash scripts/update.sh --force`)
- 인터넷이 안 되면 업데이트를 건너뛰고 현재 버전으로 실행합니다.

## 3. 친구를 초대하는 방법

서버가 켜지면 검은 창(터미널)에 이렇게 표시됩니다:

```
────────────────────────────────────────────────────
  🌋 정령섬 온라인 서버가 실행되었습니다
────────────────────────────────────────────────────
  내 컴퓨터에서 접속   : http://localhost:3000
  같은 와이파이 친구   : http://192.168.0.12:3000
  멀리 있는 친구       : 새 창에서 "npm run share" 실행 → 나오는 https 주소 공유
```

### 경우 1 — 같은 집/같은 와이파이

친구에게 **`같은 와이파이 친구`** 줄의 주소(예: `http://192.168.0.12:3000`)를 알려주세요.
접속이 안 되면 Windows 방화벽에서 Node.js 를 허용했는지 확인하세요 ([문제 해결](#5-자주-묻는-질문--문제-해결) 참고).

### 경우 2 — 서로 다른 곳 (추천: 터널)

인터넷 어디서나 접속 가능한 임시 `https` 주소를 만들어 줍니다. 공유기 설정이 필요 없습니다.

1. 서버 창은 그대로 두고, **새 명령 프롬프트/터미널**을 열어 게임 폴더로 이동합니다.
   - Windows: 게임 폴더의 주소창에 `cmd` 라고 입력하고 엔터 → 그 폴더에서 명령 프롬프트가 열립니다.
2. 다음 명령을 실행합니다:
   ```bash
   npm run share
   ```
3. 잠시 후 `https://어쩌구-저쩌구.trycloudflare.com` 같은 주소가 나옵니다. 이 주소를 친구에게 보내세요.
   - 이 창도 게임하는 동안 열어 두세요. 주소는 실행할 때마다 바뀝니다.
   - 대안: [ngrok](https://ngrok.com) 을 쓴다면 `ngrok http 3000`

### 경우 3 — 공유기 포트포워딩 (고급)

공유기 관리 페이지에서 **외부 3000번 포트 → 서버 PC의 내부 IP:3000** 으로 포워딩하고,
친구에게 `http://내공인IP:3000` 을 알려줍니다. (공인 IP는 "내 IP 확인"으로 검색)

### 방에 들어오기

1. 방장이 게임 첫 화면에서 이름을 입력하고 **새 방 만들기** → 4자리 **방 코드**가 생깁니다.
2. 대기실 위쪽의 **초대 링크 복사** 를 눌러 친구에게 보내면, 친구는 링크를 열고 이름만 입력해 **참가**하면 됩니다.
   (또는 친구가 같은 주소로 접속해 방 코드를 직접 입력)
   - 방장이 `localhost` 로 접속해 있으면 링크는 자동으로 **같은 와이파이용 주소**로 복사됩니다. 대기실 왼쪽에도 친구 접속 주소가 표시됩니다.
   - 멀리 있는 친구에게는 터널 주소(`https://...trycloudflare.com`)와 방 코드를 보내세요.
3. 방장은 대기실 왼쪽 **게임 설정**에서 확장판(DLC), 맵, 난이도를 고릅니다.
4. 각자 **정령을 고르고**(카드 클릭), 방장이 **게임 시작** 을 누릅니다.
   - 정령 카드의 **＋ 추가로 조종**을 누르면 한 사람이 정령을 여러 개 맡을 수 있어요. 게임 중에는 위쪽 "내가 조종하는 정령" 버튼으로 전환합니다(할 일이 있는 정령은 ● 표시).
   - **🎲 무작위 정령** 버튼으로 정령을 무작위로 고를 수도 있습니다.

## 4. 게임 진행 방법

### 🎬 처음이라면: 규칙 설명 영상 → 튜토리얼
1. 첫 화면에서 **🎬 규칙 설명 영상**을 누르세요. 10개 장면(게임 소개, 한 턴의 흐름, 침략자 진행표, 탐험·건설·약탈, 전투 계산, 성장과 존재, 권능 카드 사용법, 승리와 패배)이 움직이는 그림과 **한국어 음성 + 자막**으로 설명됩니다. 장면 버튼으로 원하는 부분만 다시 볼 수 있어요. (음성은 브라우저의 한국어 음성을 사용합니다. 없으면 자막만 나와요)
2. 그다음 **🎓 튜토리얼**을 누르면 혼자 연습 게임이 시작되고, **튜토리얼 코치**가 단계마다 무엇을 눌러야 하는지 화면을 강조하며 안내합니다. 침략자 단계는 천천히 한 단계씩 멈추며 설명해 줘요.

### 침략자가 어디서·언제·어떻게 오는지 보기
- 화면 위 **침략자 진행표**: `🧭 탐험 → 🏠 건설 → ⚔ 약탈`. 카드는 매 턴 오른쪽으로 한 칸씩 이동합니다.
- 지도에는 이번 턴에 **⚔ 약탈 예정 / 🏠 건설 예정**인 지역이 표시됩니다. 거기에 권능을 쓰면 피해를 막을 수 있어요.
- 침략자 단계가 진행되면 지도 위에 **배너**가 떠서 지금 어떤 카드로 어느 지역에서 무슨 일이 일어나는지 알려 줍니다.
- 카드를 고를 때 각 카드가 **실제로 무엇을 하는지 문장으로 풀어서** 보여 줍니다.
- 침략자 단계는 기본으로 **한 단계씩 멈춥니다**. 안내를 읽고 **"다 봤어요, 다음 ▶"**(또는 Enter)를 모두 누르면 다음으로 넘어가요. 방 설정 **⏱ 침략자 단계 진행**에서 "자동 · 느리게(5초) / 보통(2.5초)"로 바꿀 수 있습니다.

### ⚔ 전투 계산 (공격력·체력·다한)
| 조각 | 체력 | 공격력 |
|---|---|---|
| 탐험가 | 1 | 1 |
| 마을 | 2 | 2 (쓰러뜨리면 공포 +1) |
| 도시 | 3 | 3 (쓰러뜨리면 공포 +2) |
| 다한 (우리 편) | 2 | 반격 2 |

약탈 = ① 침략자 공격력 합계 → ② 방어만큼 빼기 = 땅에 피해 → ③ 2 이상이면 황폐 → ④ 같은 피해를 다한이 받음(2마다 1명 쓰러짐) → ⑤ 살아남은 다한 1명당 피해 2로 반격.
- 약탈할 때 **지역마다 이 계산 과정**이 화면 가운데에 나옵니다.
- 지도의 약탈 예정 지역에는 **"⚔ 약탈 피해 3 → 황폐!"**처럼 예상 결과가 표시되고, 마우스를 올리면 자세한 예상 계산이 나와요.
- 범례의 **⚔ 전투 계산법** 버튼, 규칙 설명 영상 7장 **"전투 계산"**에서 예시와 함께 다시 볼 수 있습니다. (적대 세력에 따라 침략자 공격력이 더 높아질 수 있고, 표에도 바뀐 값이 나옵니다)

- 화면 맨 위 **금색 상자**에 지금 내가 해야 할 일이 표시됩니다. 버튼을 누르거나, **지도에서 빛나는 지역**을 클릭하세요.
- 카드를 고를 때는 카드 선택 창이 뜹니다. "지도 보기"로 잠시 닫았다가 상단의 "카드 선택 창 열기"로 다시 열 수 있습니다.
- 모든 플레이어가 **동시에** 진행합니다. 내 차례가 끝나면 "다른 플레이어를 기다리는 중"이 표시됩니다.
- 오른쪽 패널: 정령별 에너지·원소·존재 트랙·내재 권능. 탭을 눌러 친구의 정령도 볼 수 있습니다.
- 지역이나 카드 이름 위에 마우스를 올리면 자세한 정보가 나옵니다.
- 상단의 **❓ 규칙** 버튼에 규칙 요약이 있습니다.
- 처음 게임을 시작하면 **게임 방법 안내**가 자동으로 뜹니다. 언제든 상단 **📖 게임 방법**으로 다시 볼 수 있어요.
- 금색 상자 아래 **💡 도움말 줄**이 지금 무엇을 해야 하는지 알려 줍니다.
- 지도: **3D**(기본) — 드래그로 회전, 휠로 확대, 우클릭 드래그로 이동. 지도 오른쪽 위 버튼으로 **2D 전환 / 시점 초기화 / 패널·손패 접기 / 전체 화면**을 할 수 있어요.
- 상단의 **🔊 소리** 버튼으로 배경음악·효과음을 켜고 끄거나 음량을 조절할 수 있습니다. (브라우저 정책상 화면을 한 번 클릭해야 소리가 나기 시작합니다)
- 새로고침하거나 연결이 잠깐 끊겨도 **같은 탭**에서 다시 접속하면 원래 자리로 돌아옵니다.

한 턴의 흐름: **성장 선택 → 에너지 획득 → 권능 카드 내기 → 빠른 권능 → 침략자 단계(공포 카드·약탈·건설·탐험) → 느린 권능 → 시간 흐름**

## 5. 자주 묻는 질문 / 문제 해결

| 증상 | 해결 |
| --- | --- |
| `start-windows.bat` 실행 시 창이 바로 꺼짐 / "node 를 찾을 수 없음" | Node.js 를 설치했는지 확인하고 컴퓨터를 재시작하세요. |
| "포트가 이미 사용 중입니다" | 서버가 이미 켜져 있습니다. 기존 검은 창을 쓰거나 닫고 다시 실행하세요. |
| 같은 와이파이 친구가 접속 못 함 | Windows 설정 → **Windows 보안 → 방화벽 및 네트워크 보호 → 방화벽에서 앱 허용** → Node.js 의 "개인" 체크. 네트워크가 "공용"으로 되어 있으면 "개인"으로 바꾸세요. 회사/학교 와이파이는 기기 간 접속이 막혀 있을 수 있으니 터널 방식을 쓰세요. |
| `npm run share` 가 안 됨 | 인터넷 연결 확인. 처음엔 cloudflared 를 내려받느라 시간이 걸립니다. 안 되면 ngrok 을 사용하세요. |
| 서버 창을 닫았더니 게임이 사라짐 | 게임 상태는 서버 메모리에 있으므로 서버를 끄면 진행 중인 게임이 사라집니다. |
| 화면이 깨지거나 글꼴이 이상함 | 크롬/엣지 최신 버전을 사용하세요. 인터넷이 안 되면 기본 글꼴로 표시됩니다. |
| macOS "확인되지 않은 개발자" | 파일 우클릭 → 열기 → 열기 |
| 소리가 안 나요 | 화면을 한 번 클릭한 뒤, 상단 🔊 소리 → **🔔 소리 테스트**를 눌러 보세요. 브라우저 탭이 음소거되어 있지 않은지(탭 우클릭), Windows 볼륨 믹서에서 브라우저 음량도 확인하세요. |
| 3D 지도가 안 나오고 2D만 보여요 | 게임 폴더에서 `npm install` 을 다시 실행하거나 `정령섬.exe` 로 실행하세요(필요한 파일을 자동 설치). 그래픽 카드가 오래된 경우 2D 지도로 표시됩니다. |
| 3D 지도가 느려요 | 지도 오른쪽 위 **2D 보기** 버튼으로 2D 지도를 쓰세요. |

## 6. 구현된 내용

- **실시간 멀티플레이**: WebSocket, 방 코드, 재접속, 채팅
- **섬**: 플레이어 수에 따라 보드 1~4개 (A~D), 지형 4종(산·정글·사막·습지), 해안/내륙, 보드 간 인접
- **정령 37종 — 원작 기본판 + 모든 확장판** (성장 옵션, 존재 트랙, 특수 규칙, 내재 권능, 고유 권능 카드 4장씩, 초보자용 팁)
  - 기본판 8 · 가지와 발톱 2 · 깃털과 불꽃(프로모 1·2) 4 · 들쭉날쭉한 대지 10 · 정령섬의 지평선 5 · 자연의 화신 8
  - 방장이 **확장판(DLC)을 켜고 끄면** 해당 정령만 선택 목록에 나옵니다
  - **한 사람이 정령 여러 개를 조종**할 수 있습니다 (정령 카드의 "＋ 추가로 조종", 게임 전체 최대 6개)
- **정령 일러스트**: 정령 37종 모두 테마에 맞춘 오리지널 일러스트(공식 그림은 저작권 때문에 포함하지 않음). 내 그림을 쓰고 싶으면 `custom-art` 폴더 안내 참고
- **정령 판(보드)**: 정령을 누르면 원작처럼 정령 판이 열리고 **뒤집기**로 앞면(특수 규칙·성장·존재 트랙·내재 권능)과 뒷면(소개·플레이 방법·시작 배치·난이도·권능 성향·고유 권능 카드)을 볼 수 있음. 게임 중에도 오른쪽 패널의 "📜 정령 판 보기"
- **맵 설정**: 보드 A~F(E·F는 들쭉날쭉한 대지), 순서대로/무작위 보드, 섬(격자)/긴 해안선(세로) 배치, 추가 보드 +1
- **난이도**: 입문 · 쉬움 · 보통 · 어려움 · 매우 어려움 프리셋 + **적대 세력 7종**(브란덴부르크-프로이센, 잉글랜드, 스웨덴, 프랑스, 러시아, 합스부르크, 스코틀랜드) 레벨 0~6
- **권능 카드**: 고유 148장, 소형 24장, 대형 10장 (대형은 원소 조건 추가 효과, 획득 시 카드 1장 잊기)
- **침략자 덱**: 1단계 3장 / 2단계 4장(해안 카드 포함) / 3단계 5장
- **공포**: 공포 풀, 공포 카드 12종 중 9장, 공포 단계 1~3과 단계별 승리 조건
- **황폐**: 황폐 카드(건강한 섬 → 황폐해진 섬), 황폐 확산, 존재 파괴 / **다한**: 약탈 피해, 반격
- **3D 지도**: 지형마다 높이가 다른 입체 섬, 산·숲·갈대 장식, 출렁이는 바다, 3D 조각 모형. 드래그로 회전, 휠로 확대 (2D 지도로 전환 가능)
- **튜토리얼**: 9단계 그림 안내(게임 방법), 상황별 💡 도움말, 현재 단계 표시
- **그래픽**: 직접 그린 조각·원소·지형 아이콘, 양피지 스타일 권능 카드
- **앱 아이콘**: Windows `정령섬.exe` (첫 실행 시 바탕화면 아이콘 자동 생성) / macOS 앱 / Linux 데스크톱 항목 / 브라우저 앱 설치(PWA)
- **사운드**: 실시간 합성 배경음악(평소엔 잔잔한 섬 테마, 침략자 단계엔 북소리가 더해진 긴장감 있는 테마)과 효과음(카드, 약탈, 건설, 황폐, 공포, 승리/패배 등). 상단의 🔊 소리 버튼으로 켜고 끄거나 음량 조절

### 단순화된 부분

- 피해 배분은 자동입니다(파괴할 수 있는 가장 가치 높은 침략자부터). 밀어내기/모으기, 대상 지정은 직접 고릅니다.
- 황폐 확산 위치는 인접 지역 중 황폐가 가장 적은 곳으로 자동 선택됩니다.
- 보드 지형과 초기 배치는 원작 보드를 참고한 근사치입니다(모든 보드가 같은 모양).
- 적대국(Adversary)/시나리오, 존재 트랙의 원소 보너스, 확장판 요소는 아직 없습니다.

## 7. 개발자용

```bash
npm run dev       # 파일 변경 시 서버 자동 재시작
npm test          # 규칙 단위 테스트 + 무작위 봇 전체 게임 시뮬레이션
npm run test:e2e  # 브라우저 2개로 방 생성→참가→게임 진행 (서버 실행 후, playwright 필요)
node test/e2e-settings.js http://localhost:3000  # 방 설정 + 정령 2개 조종 E2E
npm run icons     # public/icons/icon.svg 로부터 PNG/ICO 재생성 (playwright 필요)
```

### 구조

```
정령섬.exe                                               Windows 실행 아이콘 (launcher/build.sh 로 빌드)
start-windows.bat / start-mac.command / start-linux.sh   더블클릭 실행 파일
create-shortcut-windows.bat, scripts/                    바로가기(아이콘) 생성 스크립트
server/
  index.js          HTTP(정적 파일) + WebSocket 서버, 방/로비 관리
  game/
    game.js         게임 엔진 (턴 진행, 침략자, 공포, 황폐, 선택 처리)
    boards.js       섬 보드 모양·지형·초기 배치, 인접 자동 계산
    spirits.js      정령 정의
    powers.js       권능 카드 정의 (효과 코드 포함)
    fear.js         공포 카드
    spirits_ext.js  확장판 정령 25종 / powers_ext.js 그 고유 권능
    adversaries.js  난이도 프리셋과 적대 세력
public/
  index.html, style.css, app.js   브라우저 클라이언트 (빌드 없이 순수 HTML/CSS/JS)
  icons.js          SVG 아이콘 스프라이트 (원소, 조각, 지형, 로고)
  audio.js          배경음악·효과음 (Web Audio API 실시간 합성, 음원 파일 없음)
  map3d.js          3D 지도 (three.js, ES 모듈)
  guide.js          게임 방법 안내 슬라이드 + 상황별 도움말
  icons/            앱 아이콘 (svg/png/ico), manifest.webmanifest, sw.js (앱 설치용)
test/               테스트
```

게임 엔진은 `async` 함수로 진행되며, 플레이어의 선택이 필요하면 `await game.ask(...)`로 멈추고
클라이언트의 응답을 기다립니다. 새 카드는 `powers.js`에 `effect(ctx)`를 작성해 추가할 수 있습니다.
