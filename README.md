# 🌋 정령섬 온라인 (Spirit Island Online)

협력 보드게임 **정령섬(Spirit Island)** 을 친구와 함께 각자의 컴퓨터에서 브라우저로 플레이할 수 있게 만든 팬메이드 구현입니다.
한 사람이 서버를 실행하고, 다른 사람들은 브라우저로 접속해 방 코드로 들어오면 됩니다. (1~4인)

> 비공식 팬 프로젝트입니다. 정령섬은 R. Eric Reuss / Greater Than Games의 저작물입니다.
> 카드 효과는 원작을 바탕으로 했지만, 온라인 진행을 위해 일부 단순화되어 있습니다.

## 빠른 시작

필요한 것: [Node.js](https://nodejs.org/) 18 이상

```bash
git clone <이 저장소 주소>
cd SpiritIsland
npm install
npm start
```

브라우저에서 `http://localhost:3000` 을 엽니다.

1. 이름을 입력하고 **방 만들기** → 4자리 방 코드가 생깁니다.
2. 친구는 같은 서버 주소로 접속해 **방 코드**를 입력하고 **참가** (또는 "링크 복사"로 초대 링크 공유).
3. 각자 정령을 고르고, 방장이 **게임 시작**.

포트를 바꾸려면 `PORT=8080 npm start`.

## 친구와 연결하는 방법

서버를 실행한 컴퓨터에 친구가 접속할 수 있어야 합니다.

| 상황 | 방법 |
| --- | --- |
| 같은 와이파이/공유기 | 서버 PC의 내부 IP로 접속: `http://192.168.x.x:3000` (Windows: `ipconfig`, macOS: `ipconfig getifaddr en0`). 방화벽에서 Node.js 허용 필요 |
| 서로 다른 곳 (가장 쉬움) | 터널 서비스 사용: `npx cloudflared tunnel --url http://localhost:3000` 또는 `ngrok http 3000` → 나오는 `https://...` 주소를 친구에게 공유 |
| 서로 다른 곳 (포트포워딩) | 공유기에서 3000번 포트를 서버 PC로 포워딩하고 공인 IP로 접속 |
| 항상 켜두기 | Render, Railway, Fly.io 같은 Node.js 호스팅에 배포 (`npm start`, WebSocket 지원 필요) |

새로고침하거나 연결이 잠깐 끊겨도 같은 탭에서 다시 접속하면 자동으로 원래 자리로 돌아옵니다.
(서버를 재시작하면 진행 중인 게임은 사라집니다.)

## 구현된 내용

- **실시간 멀티플레이**: WebSocket, 방 코드, 재접속, 채팅
- **섬**: 플레이어 수에 따라 보드 1~4개 (A~D), 지형 4종(산·정글·사막·습지), 해안/내륙, 보드 간 인접
- **정령 4종** (성장 옵션, 에너지/카드 존재 트랙, 특수 규칙, 내재 권능, 고유 권능 카드 4장씩)
  - 번개의 신속한 일격 — 공기 원소로 느린 권능을 빠르게
  - 햇살 속에 굽이치는 강 — 습지의 존재는 성지
  - 대지의 활력 — 성지에 방어 3
  - 불꽃처럼 일렁이는 그림자 — 에너지 1로 다한이 있는 곳을 사거리 무시하고 대상 지정
- **권능 카드**: 고유 16장, 소형 24장, 대형 10장 (대형은 원소 조건 추가 효과, 획득 시 카드 1장 잊기)
- **턴 진행**: 성장 → 에너지 → 카드 내기 → 빠른 권능 → 침략자 단계(공포 카드 → 약탈 → 건설 → 탐험) → 느린 권능 → 시간 흐름
- **침략자 덱**: 1단계 3장 / 2단계 4장(해안 카드 포함) / 3단계 5장
- **공포**: 공포 풀, 공포 카드 12종 중 9장, 공포 단계 1~3과 단계별 승리 조건
- **황폐**: 황폐 카드(건강한 섬 → 황폐해진 섬), 황폐 확산, 존재 파괴
- **다한**: 약탈 피해, 반격
- 모든 플레이어가 **동시에** 성장·카드 선택·권능 사용을 진행합니다.

### 단순화된 부분

- 피해 배분은 자동입니다(파괴할 수 있는 가장 가치 높은 침략자부터). 밀어내기/모으기, 대상 지정은 직접 고릅니다.
- 황폐 확산 위치는 인접 지역 중 황폐가 가장 적은 곳으로 자동 선택됩니다.
- 보드 지형과 초기 배치는 원작 보드를 참고한 근사치입니다(모든 보드가 같은 모양).
- 적대국(Adversary)/시나리오, 존재 트랙의 원소 보너스, 확장판 요소는 아직 없습니다.

## 개발

```bash
npm run dev     # 파일 변경 시 서버 자동 재시작
npm test        # 규칙 단위 테스트 + 무작위 봇 전체 게임 시뮬레이션
# E2E (브라우저 2개로 방 생성→참가→게임 진행), playwright 필요
node test/e2e.js http://localhost:3000 3
```

### 구조

```
server/
  index.js          HTTP(정적 파일) + WebSocket 서버, 방/로비 관리
  game/
    game.js         게임 엔진 (턴 진행, 침략자, 공포, 황폐, 선택 처리)
    boards.js       섬 보드 모양·지형·초기 배치, 인접 자동 계산
    spirits.js      정령 정의
    powers.js       권능 카드 정의 (효과 코드 포함)
    fear.js         공포 카드
public/             브라우저 클라이언트 (빌드 없이 순수 HTML/CSS/JS)
test/               테스트
```

게임 엔진은 `async` 함수로 진행되며, 플레이어의 선택이 필요하면 `await game.ask(...)`로 멈추고
클라이언트의 응답을 기다립니다. 새 카드는 `powers.js`에 `effect(ctx)`를 작성해 추가할 수 있습니다.
